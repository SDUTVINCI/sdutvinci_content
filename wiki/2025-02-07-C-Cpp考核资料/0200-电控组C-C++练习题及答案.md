```C++
            if (nums[j] > nums[j + 1]) {
```

#### 与运算符（\&）

与运算符对两个操作数的每一位执行逻辑与操作。只有当两个对应位都为1时，结果位才为1，否则为0。

#### 或运算符（\|）

或运算符对两个操作数的每一位执行逻辑或操作。只要有一个对应位为1，结果位就为1。

#### 异或运算符（^）

异或运算符对两个操作数的每一位执行逻辑异或操作。当两个对应位不同，结果位为1；相同，结果位为0。

`^`运算符满足`交换律`和`结合律`。

#### 取反运算符（\~）

取反运算符对操作数的每一位执行逻辑取反操作。0变1，1变0。

#### 左移运算符（\<\<）

左移运算符将操作数的所有位向左移动指定的位数，右边补0。左移n位相当于乘以2的n次方。

示例：

`int a = 5; // 二进制: 0000 0101`

`int b = a << 1; // 左移1位，结果: 0000 1010，即10`

#### 右移运算符（\>\>）

右移运算符将操作数的所有位向右移动指定的位数。对于无符号数，左边补0；对于有符号数，补符号位（算术右移）或补0（逻辑右移）。

示例：

int a = 5; // 二进制: 0000 0101

int b = a \>\> 1; // 右移1位，结果: 0000 0010，即2

## **题目：请使用联合体来完成输入一个字母，并打印他的****ascii码****。 **

![image3\.png](http://10.0.0.4:5244/COS/tungwebsite/assets/images/wiki/2025/02/07/76ef0fd904953444.webp)

```C++
#include <iostream>

using std::cout;
using std::cin;
using std::endl;

union Convert
{
    int asc;
    char letter;
};

typedef Convert con;

con con__;  //有的编译器需要初始化后三个字节，所以需要用全局变量。

int main()
{
    cin >> con__.letter;
    cout << con__.asc << endl;
    return 0;
}
```

这里体现了联合体公用一块内存，以及小端存储的特性：

1. 假如当cin输入一个字符c时，由于c的ascii码为99，其在内存中的顺序为：

99 00 00 00（十六进制格式）

当读取时，由于letter和asc共用一块内存，char占1字节，int占4字节，但是因为是小端存储，排在前面的是低地址位，所以读取出来的是0x000099，故输出的为99，即ascii码

2. 假如是大端存储，那么读取出来的就是0x99000000，即1660944384

## 在许多数据协议中，数据串都是以字节\(uint8\_t\)为单位发送的。但是1个字节的数据只能存放8位二进制数据，有的数据需要16位甚至更多二进制才能存放，所以我们在传送一个数据的时候，通常要连续发送若干个字节，这若干个字节构成一个数据。               现在，我们需要处理我们接收到的数据串，一共有2个字节，该协议规定，第一个字节为数据的高8位（DH），第二个字节为数据的低8位（DL）。请创建一个函数 ' int16\_t data\_calc\(uint8\_t DH,uint8\_t DL\) ' ，该函数的作用是将这两个字节的数据串，进行数据处理，处理成一个有符号短整型（int16\_t）的数据。DH我们规定是0x50，DL是0x2E。\[tips: uint8\_t就是unsigned char的别名，int16\_t就是short int的别名，都是由typedef关键字起别名而来，C\+\+头文件中自带该别名，可以直接使用\]

![image\.png](http://10.0.0.4:5244/COS/tungwebsite/assets/images/wiki/2025/02/07/f116da3a9aaa2d21.webp)

```C++
#include <iostream>
#include <ios>   //hex和dec是该头文件下的std命名空间中的

using std::cout;
using std::cin;
using std::endl;

/*  常用的别名（部分C++自带，不用咱们写）
typedef unsigned char byte;
typedef unsigned char uint8_t;
typedef short int int16_t;
typedef float fp32;
typedef double fp64;
*/

int16_t data_calc(uint8_t DH,uint8_t DL);

int main()
{
    uint8_t DH = 0x50,DL = 0x2E;
    cout << "高8位DH:";
    cout << std::hex << "0x" << (int)DH << endl;
    cout << "低8位DL:";
    cout << std::hex << "0x" << (int)DL << endl;   //此行的hex可以不写
    auto DATA = data_calc(DH,DL);
    cout << "经数据处理后的结果是:" << std::dec << DATA << "\n";

    return 0;
}

int16_t data_calc(uint8_t Data_H,uint8_t Data_L)
{
    int16_t Data = (int16_t)((int16_t)Data_H << 8 | Data_L);
    return Data;
}
```

①请定义一个叫stru\_lib的库\(stru\_lib\.cpp和stru\_lib\.h\)。

②stru\_lib库内有一个命名空间叫ns\_demo。

print\_student\_info函数用于打印stu类型的结构体变量的所有成员变量。

## 现代C\+\+之基础

要求：

- 定义基类 `BaseCalculator`，成员函数：

```C++
void do_calculation(int x, int y);
```

- 这个函数里面会调用一个储存在该类里的私有的回调函数（`std::function<int(int,int)>`），并打印回调结果。

- 该类里的所有成员函数不准直接出现两个数据相加的功能。

- 该基类里可能不止一个成员函数，这算是一个提示。

- 里面所有的打印请使用现代C\+\+里的std::print或者std::println。

- 如果编译器支持标准库模块化的话，可以选择使用modules。\(标准库模块化在C\+\+26将全面支持，而在C\+\+20，C\+\+23中仅MSVC编译器支持比较好）



- 定义派生类 `AddCalculator`，继承 `BaseCalculator`，在这个类里实现能让两个数据相加的功能。

- `main()` 里，创建 `AddCalculator` 对象，调用基类的 `do_calculation(10, 20)`，打印结果。

这题至少两种写法，尽量可以写出2种写法。

![image\.png](http://10.0.0.4:5244/COS/tungwebsite/assets/images/wiki/2025/02/07/a0444bb6dd55cdb8.webp)

方法一：采用bind

```C++
import std.io;       // 代替 #include <iostream>
import std.functional; // 代替 #include <functional>
import std.print;    // 代替 #include <print>

class BaseCalculator
{
public:
    // 绑定回调函数
    void set_callback(std::function<int(int,int)> cb)
    {
        callback_ = std::move(cb);
    }

    // 调用回调并打印结果
    void do_calculation(int x, int y)
    {
        if(callback_)
        {
            int result = callback_(x, y);
            std::println("Calculation result: {}", result);
        }
    }

private:
    std::function<int(int,int)> callback_;
};

class AddCalculator : public BaseCalculator
{
public:
    AddCalculator()
    {
        // 绑定成员函数 add，传入 this
        set_callback(std::bind(&AddCalculator::add, this, std::placeholders::_1, std::placeholders::_2));
    }

    int add(int a, int b)
    {
        return a + b;
    }
};

int main()
{
    AddCalculator calc;

    calc.do_calculation(10, 20);  // 输出 Calculation result: 30

    std::println("Press Enter to continue...");
    std::cin.get();
    return 0;
}
```

方法二：采用lambda表达式

```C++
import std.io;       // 代替 #include <iostream>
import std.functional; // 代替 #include <functional>
import std.print;    // 代替 #include <print>

class BaseCalculator
{
public:
    void set_callback(std::function<int(int,int)> cb)
    {
        callback_ = std::move(cb);
    }

    void do_calculation(int x, int y)
    {
        if(callback_)
        {
            int result = callback_(x, y);
            std::println("Calculation result: {}", result);  // 自动换行
        }
    }

private:
    std::function<int(int,int)> callback_;
};

class AddCalculator : public BaseCalculator
{
public:
    AddCalculator()
    {
        // 用lambda捕获this
        set_callback([this](int a, int b)
        {
            return a + b;
        });
    }
};

int main()
{
    AddCalculator calc;

    calc.do_calculation(10, 20);  // 输出 Calculation result: 30

    std::println("Press Enter to continue...");  // 自动换行
    std::cin.get();
    return 0;
}
```
