# 26届VINCI战队嵌入式/算法组纳新考核参考答案与评分标准


考核范围为培养计划“C++（优先学）”第1—14、17—23部分。

## 评分说明

- 选择题、判断题每题2分，答对得2分，答错或未答得0分。
- 编程题按功能与分项评分点给分，接受正确等价写法。
- 编程题1—3为完善程序，4—6为编写函数，7—10为编写完整程序。
- 编程题分值依次为6、6、6、6、6、6、8、8、9、9分，共70分。
- 涉及命名空间或`Mode`枚举参数的题按C++评分；其他题接受符合题意的C或C++实现。
- 参考实现按C++11编译，第1题也可按C11编译。函数题由调用程序测试，每道完整程序独立运行。
- 简答题接受同义表述，按所列评分点给分。

## 一、单项选择题答案（共10分）

| 题号 | 答案 | 分值 |
| --- | --- | ---: |
| 1 | B | 2分 |
| 2 | C | 2分 |
| 3 | A | 2分 |
| 4 | D | 2分 |
| 5 | B | 2分 |

### 第1题

**答案：B。** 标识符不能以数字开头，不能使用关键字，也不能包含减号。

### 第2题

**答案：C。** 整型除法7/2为3，7%2为1，因此结果为4。

### 第3题

**答案：A。** 内层同名变量屏蔽外层变量，内层修改不改变外层count。

### 第4题

**答案：D。** 不带初始化的extern int total;是声明。使用该变量时还需要对应的定义。

### 第5题

**答案：B。** 联合体成员共享存储，其大小至少能容纳最大的成员，并可能包含对齐填充。

| 题号 | 答案 | 分值 |

| 1 | 正确 | 2分 |
| 2 | 错误 | 2分 |

### 第1题

**答案：正确。** std是标准库命名空间，std::cout是其输出流对象。

### 第2题

**答案：错误。** 有效下标是0至4。

**答案：正确。** do-while先执行循环体，再判断条件。

### 第4题

### 编程题9：连续达标次数（9分）

题目形式：编写完整代码。考查培养计划第7、11、13部分。

**参考代码**

```cpp
#include <iostream>
int main() {
    int n = 0, threshold = 0, a[20] = {0};
    std::cin >> n >> threshold;
    for (int i = 0; i < n; ++i) std::cin >> a[i];
    int current = 0, best = 0;
    for (int i = 0; i < n; ++i) {
        if (a[i] >= threshold) ++current;
        else current = 0;
        if (current > best) best = current;
    }
    std::cout << best << "\n";
    return 0;
}
```

**评分标准**

输入和数组2分；达标条件包含等号2分；连续计数和中断清零2分；更新最长值2分；输出及无达标情况1分。

### 编程题10：二维数据统计（9分）

**参考代码**

```cpp
#include <iostream>
int main() {
    int a[3][4] = {0}, rowSum[3] = {0};
    for (int i = 0; i < 3; ++i) {
        for (int j = 0; j < 4; ++j) {
            std::cin >> a[i][j];
            rowSum[i] += a[i][j];
        }
    }
    int best = 0;
    for (int i = 1; i < 3; ++i) {
        if (rowSum[i] > rowSum[best]) best = i;
    }
    std::cout << best + 1 << " " << rowSum[best] << "\n";
    return 0;
}
```

## 四、分组简答题参考答案（各组共10分）

单意向者只作答对应组别的两道题；双意向者分别计入两组成绩。

### 嵌入式组

#### 第1题：单片机是什么？用自己的话简要说明。（5分）

**参考答案**

单片机又称单片微控制器，是把处理器、存储器及输入输出等功能集成在一块芯片上的小型控制器，可运行程序完成控制任务。

**评分标准**

指出“单片微控制器”或“小型控制器”2分；说明多种功能集成在单个芯片上2分；说明可通过程序实现控制1分。

选自题库“控制”部分的“单片机是什么”。

#### 第2题：通讯协议是什么？用自己的话简要说明。（5分）

**参考答案**

通信协议是通信双方为交换信息而共同遵守的规则和约定，例如规定数据格式、发送和接收方式等。

**评分标准**

指出通信双方共同遵守2分；指出规则和约定2分；说明用于信息交换，或举出数据格式等合理例子1分。

选自题库“控制”部分的“通讯协议是什么”。

### 算法组

#### 第1题：Linux中的root是什么？简要说明其账户性质与权限特点，并举出一种可进行的管理操作。（5分）

**参考答案**

root是Linux系统中的超级用户或系统管理员账户，通常具有最高系统管理权限，可管理软件、配置和文件等。

**评分标准**

指出超级用户或系统管理员账户2分；指出最高管理权限2分；举出一种合理管理操作1分。

选自题库“视觉算法”部分的“Linux中的root是什么”。

#### 第2题：基于Linux的系统、发行版请列举两个。（5分）

**参考答案**

例如Ubuntu、Arch Linux。题库还列有Android、Sailfish OS、OpenWrt。其他正确例子如Debian、Fedora也可。

**评分标准**

每个不同的正确名称2.5分，共5分。同一系统的不同版本只算一个。只列出一个正确名称得2.5分。

选自题库“视觉算法”部分的“基于Linux的系统、发行版请列举（列举2个即可）”。
