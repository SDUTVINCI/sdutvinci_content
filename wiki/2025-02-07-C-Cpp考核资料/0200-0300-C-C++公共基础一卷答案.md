### 11\.编写一个函数，使用 while 循环计算从 1 到给定正整数 n 的所有整数的和。在主函数中，接受用户输入的一个正数 n，然后调用函数计算和，并输出结果。

![image\.png](https://cdn.sdutvincirobot.top/site-assets/images/wiki/2025/02/07/ed4c6253e4f3166c.webp)

```C++
#include <iostream>

int calculateSum(int n);

int main() {
    int n;
    std::cout << "请输入n: ";
    std::cin >> n;

    int sum = calculateSum(n);

    std::cout << "从1一直加到" << n << "等于: " << sum << std::endl;

    return 0;
}

int calculateSum(int n) {
    int sum = 0;
    int i = 1;
    while (i <= n) {
        sum += i;
        i++;
    }
    return sum;
}
```

### 14\.冒泡排序：编写一个函数，作用是使用冒泡排序算法对给定的整数数组进行升序排序。在主函数中，创建一个含有5个元素的整数数组并初始化，然后调用该函数对数组进行排序，并在主函数中输出排序后的结果。

![image\.png](https://cdn.sdutvincirobot.top/site-assets/images/wiki/2025/02/07/ecd3660084d827d3.webp)

```C++
#include <iostream>

void bubbleSort(int* arr, int size);

int main() {
    int arr[] = { 5, 2, 8, 3, 1 };
    int size = sizeof(arr) / sizeof(arr[0]);

    std::cout << "原始数组: ";
    for (int i = 0; i < size; i++) {
        std::cout << arr[i] << " ";
    }

    bubbleSort(arr, size);

    std::cout << "\n排列后的数组: ";
    for (int i = 0; i < size; i++) {
        std::cout << arr[i] << " ";
    }

    return 0;
}


void bubbleSort(int* arr, int size) {
    for (int i = 0; i < size - 1; i++) {
        for (int j = 0; j < size - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

### 16\.编写一个名为 calculate 的函数，该函数接受两个单精度浮点数为参数，并返回它们相乘的结果。然后，重载该函数，使其能够接受三个整形参数，其中第三个参数为默认值为0的整数。当使用两个参数调用该函数时，函数应该返回这两个整数的和；当使用三个参数调用该函数时，函数应该返回前两个整数的和加上第三个整数。在主函数中，请定义5个变量，（整形x，y，z，浮点型p和q，随便赋值一个数），分别使用 calculate 函数计算并打印出①p和q相乘后的值，②x和y相加后的值，③x，y和z相加后的值。

![image\.png](https://cdn.sdutvincirobot.top/site-assets/images/wiki/2025/02/07/c3554a16eff73369.webp)

```C++
#include <iostream>

int calculate(float a, float b);
int calculate(int a, int b, int c = 0);

int main() {
    int x = 5, y = 10, z = 20;
    float p = 4.0,q = 5.0;

    std::cout << "Multi of p and q: " << calculate(p, q) << std::endl;
    std::cout << "Sum of x, y: " << calculate(x, y) << std::endl;
    std::cout << "Sum of x, y, and z: " << calculate(x, y, z) << std::endl;

    return 0;
}


int calculate(float a, float b) {
    return (a * b);
}

int calculate(int a, int b, int c) {
    return (a + b + c);
}

```
