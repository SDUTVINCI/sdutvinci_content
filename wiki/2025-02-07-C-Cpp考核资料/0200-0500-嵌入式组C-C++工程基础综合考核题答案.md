### 11\.利用海伦公式求三角形面积\(10分=数学逻辑5\+其他5\)

海伦公式是这样的，如果一个三角形的三边长为a，b，c，设p=（a\+b\+c）/2，则三角形的面积：

![image\.png](https://cdn.sdutvincirobot.top/site-assets/images/wiki/2025/02/07/db748218262c48ec.webp)

![image\.png](https://cdn.sdutvincirobot.top/site-assets/images/wiki/2025/02/07/db8de34eaa946730.webp)

![image\.png](https://cdn.sdutvincirobot.top/site-assets/images/wiki/2025/02/07/4629e48165e7a57d.webp)

```C++
#include <iostream>
#include <cmath>
#include <stdlib.h>

using std::cout;
using std::cin;
using std::endl;

int main()
{
    double a, b, c, p, area;
    cout << "请输入3条边长:";
    cin >> a >> b >> c;
    if (a + b > c && b + c > a && a + c > b)
    {
        p = (a + b + c) / 2.0;
        area = sqrt(p * (p - a) * (p - b) * (p - c));
        cout << "三角形的面积是:" << area << endl;
    }
    else
        cout << "这3个数无法组成三角形!" << endl;
    system("pause");
    return 0;
}
```

将一个整数分解质因数。例如：输入90,打印出90=2\*3\*3\*5

![image\.png](https://cdn.sdutvincirobot.top/site-assets/images/wiki/2025/02/07/1ae6bbbb1ee2be26.webp)

```C++
#include <iostream>
#include <stdlib.h>

using std::cout;
using std::cin;
using std::endl;

int main()
{
    int i, n;
    cout << "输入需要分解的整数：";
    cin >> n;
    cout << "分解后的结果是:";
    for (i = 2; i <= n; i++)
    {
        while (n % i == 0)
        {
            cout << i;
            n /= i;
            if (n != 1)
            {
                cout << "*";
            }
        }
    }
    cout << endl;
    system("pause");
    return 0;
}
```

### 16\.现代C\+\+

请你设计一个“计算器系统”，包括：

1. 一个基类 `BaseCalculator`，用于统一接口，内部拥有一个 `std::function<int(int,int)>` 类型的回调函数 `callback_`。

2. 提供 `set_callback` 和 `get_callback` 两个接口来设置和获取这个回调函数。

3. 提供一个 `do_calculation(int x, int y)` 函数，调用 `callback_` 进行计算并打印结果。



然后设计两个派生类：

🔹 类 `AddCalculator`：

- 在构造函数中，将自身的 `add(int, int)` 成员函数通过 bind 绑定为回调。

- `add` 函数返回两数之和。



🔹 类 `MultiplyCalculator`：

- 本类里不准出现`multiply(int, int)`这种乘法函数。

- 在构造函数中，请直接将 lambda表达式 绑定为回调。



最终在 `main()` 中：

1. 在堆区创建 `AddCalculator` 对象并调用 `do_calculation(10, 5)` → 输出结果为 15

2. 在堆区创建 `MultiplyCalculator` 对象并调用 `do_calculation(10, 5)` → 输出结果为 50

3. 将 `AddCalculator` 的回调借给 `MultiplyCalculator`，再调用 `do_calculation(10, 5)` → 输出结果为 15

![image\.png](https://cdn.sdutvincirobot.top/site-assets/images/wiki/2025/02/07/7ad9f362703bc59f.webp)



```C++
#include <iostream>
#include <functional>
#include <memory>

// 基类
class BaseCalculator
{
public:
    void set_callback(std::function<int(int,int)> cb)
    {
        callback_ = std::move(cb);
    }

    std::function<int(int,int)> get_callback() const
    {
        return callback_;
    }

    void do_calculation(int x, int y)
    {
        if (callback_)
        {
            int result = callback_(x, y);
            std::cout << "Result: " << result << std::endl;
        }
    }

private:
    std::function<int(int,int)> callback_;
};

// 派生类：加法
class AddCalculator : public BaseCalculator
{
public:
    AddCalculator()
    {
        set_callback(std::bind(&AddCalculator::add,this,std::placeholders::_1, std::placeholders::_2));
    }

private:
    int add(int a, int b)
    {
        return a + b;
    }
};

// 派生类：乘法
class MultiplyCalculator : public BaseCalculator
{
public:
    MultiplyCalculator()
    {
        set_callback([this](int a, int b)
        {
            return a * b;
        });
    }

};

// 主函数
int main()
{
    auto add_calc = std::make_shared<AddCalculator>();
    auto mul_calc = std::make_shared<MultiplyCalculator>();

    add_calc->do_calculation(10, 5);   // 输出 15
    mul_calc->do_calculation(10, 5);   // 输出 50

    // 用加法替换乘法的回调
    mul_calc->set_callback(add_calc->get_callback());
    mul_calc->do_calculation(10, 5);   // 输出 15

    return 0;
}
```
