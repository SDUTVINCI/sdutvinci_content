### **单选 01｜在文件作用域写下\`int system\_mode;\` 且没有显式初始化。程序开始运行时，\`system\_mode\` 的值是（　）。  \[3分\]**

A．0

B．随机值

C．1

D．编译错误

**答案**｜A

**解析**｜具有静态存储期的整型对象在没有显式初始化时会先进行零初始化，因此初值为 0。



### **单选 02｜执行下列代码后，输出结果是（　）。  \[3分\]**

```C++
int a = 6;
int b = a;
int* p = &a;
*p = 9;
std::cout << a << " " << b;
```

A．6 6

B．9 9

C．9 6

D．6 9

**答案**｜C

**解析**｜\`b = a\` 只复制当时的值 6；\`p\` 保存 \`a\` 的地址，\`\*p = 9\` 修改的是 \`a\`，不会修改独立对象 \`b\`。

## **编程题 1｜变量赋值与数值换算  8分**

**任务**｜编写完整程序：输入两个整数 \`raw\` 和 \`offset\`。先执行 \`int corrected = raw;\`，再将 \`offset\` 加到 \`corrected\`；若结果小于 0 则改为 0，若大于 4095 则改为 4095。定义常量 \`REF\_VOLTAGE = 3\.3\`，按 \`voltage = corrected \* REF\_VOLTAGE / 4095\.0\` 计算电压并保留两位小数。输入 \`2000 100\` 时输出 \`raw=2000\`、\`corrected=2100\`、\`voltage=1\.69V\`。最后用一句话解释为什么修改 \`corrected\` 不会改变 \`raw\`。

**考查点**｜变量、常量、赋值复制、数据类型、运算符、if/else、浮点除法

### **参考答案**

```C++
#include <iomanip>
#include <iostream>

int main() {
    const double REF_VOLTAGE = 3.3;
    int raw = 0;
    int offset = 0;
    std::cin >> raw >> offset;

    int corrected = raw;
    corrected += offset;
    if (corrected < 0) {
        corrected = 0;
    } else if (corrected > 4095) {
        corrected = 4095;
    }

    double voltage = corrected * REF_VOLTAGE / 4095.0;
    std::cout << "raw=" << raw << '\n';
    std::cout << "corrected=" << corrected << '\n';
    std::cout << std::fixed << std::setprecision(2)
              << "voltage=" << voltage << "V\n";
    return 0;
}
```

**关键说明**｜\`corrected = raw\` 复制的是值。随后两个 \`int\` 对象占用各自存储，修改 \`corrected\` 不会反向改变 \`raw\`。

|评分点|分值|
|---|---|
|变量、常量与输入初始化正确|2|
|完成赋值复制与 offset 累加|1|
|上下界处理正确|2|
|电压公式和浮点除法正确|2|

## **编程题 2｜函数编写与值传递  10分**

**任务**｜声明并定义 \`void addOne\(int value\)\`，在函数内执行 \`value \+= 1\`；再声明并定义 \`int stepValue\(int start, int step, int times\)\`，使用 \`while\` 循环把 \`step\` 累计 \`times\` 次并返回结果。在 \`main\` 中令 \`int n = 10\`，调用 \`addOne\(n\)\` 后输出 \`n\`，再输出 \`stepValue\(n, 3, 4\)\`。预期结果分别为 10 和 22，并解释第一个结果。

**考查点**｜函数声明、定义、调用、返回值、局部变量、while、值传递

### **参考答案**

```C++
#include <iostream>

void addOne(int value);
int stepValue(int start, int step, int times);

int main() {
    int n = 10;
    addOne(n);
    std::cout << n << '\n';
    std::cout << stepValue(n, 3, 4) << '\n';
    return 0;
}

void addOne(int value) {
    value += 1;
}

int stepValue(int start, int step, int times) {
    int current = start;
    int count = 0;
    while (count < times) {
        current += step;
        ++count;
    }
    return current;
}
```

**关键说明**｜\`addOne\(n\)\` 把 10 复制给形参 \`value\`；函数只把副本改成 11，所以主函数中的 \`n\` 仍为 10。

## **编程题 3｜指针与结构体  14分**

**任务**｜定义 \`struct Motor \{ int id; int speed; bool enabled; \};\`。实现 \`bool setSpeed\(Motor\* motor, int newSpeed\)\`：空指针或速度不在 \-5000～5000 时返回 \`false\`，否则写入速度、将 \`enabled\` 设为 \`true\` 并返回 \`true\`。实现 \`void stopMotor\(Motor\* motor\)\`：非空时把速度设为 0、使能设为 \`false\`。在 \`main\` 中创建 \`Motor m = \{1, 1200, true\}\` 和 \`Motor\* p = \&m\`，输出 \`\&m\` 与 \`p\`，依次调用 \`setSpeed\(p, 1500\)\`、\`stopMotor\(\&m\)\` 并打印每步结果。说明两个地址为什么相同、函数为什么能修改原结构体。

**考查点**｜结构体对象、取地址、指针值、空指针、\`\-\>\`、通过地址修改原对象

struct Motor {
    int id;
    int speed;
    bool enabled;
};

bool setSpeed(Motor* motor, int newSpeed);

### **参考答案**

```C++
#include <iostream>

struct Motor { int id; int speed; bool enabled; };

bool setSpeed(Motor* motor, int newSpeed) {
    if (motor == nullptr ||
        newSpeed < -5000 || newSpeed > 5000) return false;
    motor->speed = newSpeed; motor->enabled = true;
    return true;
}

void stopMotor(Motor* motor) {
    if (motor == nullptr) return;
    motor->speed = 0; motor->enabled = false;
}

void printMotor(const Motor* motor) {
    if (motor == nullptr) return;
    std::cout << "id=" << motor->id << ", speed=" << motor->speed
              << ", enabled=" << motor->enabled << '\n';
}

int main() {
    Motor m = {1, 1200, true};
    Motor* p = &m;
    std::cout << "&m=" << &m << "\np =" << p << '\n';
    setSpeed(p, 1500); printMotor(&m);
    stopMotor(&m); printMotor(p);
    return 0;
}
```

**关键说明**｜\`p\` 中保存 \`m\` 的地址，所以 \`p\` 与 \`\&m\` 的数值相同。函数得到这个地址值的副本后，仍能沿地址访问并修改 \`m\`。

## **编程题 5｜混合应用：采样通道分析  16分**

**任务**｜定义 \`enum State \{ NORMAL, ALERT \};\` 和结构体 \`Channel\`，其中包含 \`id\`、6 个整型样本、\`minimum\`、\`maximum\`、\`average\`、\`state\`。实现 \`int sumSamples\(const int\* data, int length\)\`；实现 \`void findMinMax\(const int\* data, int length, int\* minValue, int\* maxValue\)\`；实现 \`void analyze\(Channel\* channel, int threshold\)\`，计算最小值、最大值和平均值，平均值大于等于阈值时设为 \`ALERT\`；实现 \`void printChannel\(const Channel\* channel\)\`，使用 \`switch\` 输出状态。\`main\` 中使用样本 \`\{62, 68, 75, 80, 85, 90\}\`、阈值 75，应得到 \`minimum=62\`、\`maximum=90\`、\`average=76\.67\`、\`state=ALERT\`。

**考查点**｜枚举、结构体、数组、for、函数、指针、输出参数、if、switch、综合调试

```C++
enum State { NORMAL, ALERT };

struct Channel {
    int id;
    int samples[6];
    int minimum;
    int maximum;
    double average;
    State state;
};
```

### **参考答案**

```C++
#include <iomanip>
#include <iostream>

enum State { NORMAL, ALERT };

struct Channel {
    int id;
    int samples[6];
    int minimum;
    int maximum;
    double average;
    State state;
};

int sumSamples(const int* data, int length) {
    int sum = 0;
    for (int i = 0; i < length; ++i) {
        sum += data[i];
    }
    return sum;
}

void findMinMax(const int* data, int length,
                int* minValue, int* maxValue) {
    if (data == nullptr || minValue == nullptr ||
        maxValue == nullptr || length <= 0) return;
    *minValue = data[0];
    *maxValue = data[0];
    for (int i = 1; i < length; ++i) {
        if (data[i] < *minValue) *minValue = data[i];
        if (data[i] > *maxValue) *maxValue = data[i];
    }
}

void analyze(Channel* channel, int threshold) {
    if (channel == nullptr) return;
    findMinMax(channel->samples, 6,
               &channel->minimum, &channel->maximum);
    channel->average = sumSamples(channel->samples, 6) / 6.0;
    channel->state =
        (channel->average >= threshold) ? ALERT : NORMAL;
}

void printChannel(const Channel* channel) {
    if (channel == nullptr) return;
    std::cout << "id=" << channel->id
              << ", minimum=" << channel->minimum
              << ", maximum=" << channel->maximum
              << ", average=" << std::fixed << std::setprecision(2)
              << channel->average << ", state=";
    switch (channel->state) {
        case NORMAL: std::cout << "NORMAL\n"; break;
        case ALERT:  std::cout << "ALERT\n"; break;
    }
}

int main() {
    Channel channel =
        {7, {62, 68, 75, 80, 85, 90}, 0, 0, 0.0, NORMAL};
    analyze(&channel, 75);
    printChannel(&channel);
    return 0;
}
```

**关键说明**｜数组首地址传给求和与最值函数；最小值和最大值通过两个输出指针写回结构体成员；结构体地址传给 analyze 后，函数写回 average 与 state。

### **评分标准与检查**

**预期输出**｜\`id=7, minimum=62, maximum=90, average=76\.67, state=ALERT\`。

|`findMinMax` 使用输出指针正确写回最值|4|
|`analyze` 计算平均值并设置状态|3|
|`printChannel` 使用 switch，主函数按地址调用|2|

## **高频失分点**



**值与地址混淆**｜把赋值复制误认为两个变量共享存储，或把地址当成对象的数值。



**未初始化**｜读取未初始化局部变量，或解引用未指向有效对象的指针。



**传参表述不准**｜把“指针值按值传递、再间接修改对象”误称为引用传递。



**跨文件定义错误**｜在头文件直接定义普通全局变量，导致多重定义；或忘记把实现源文件加入编译。



**边界错误**｜循环写成 \`i \<= length\`，或没有检查长度、空指针和允许范围。
