## 简介

本文介绍 Linux 下的手柄检测、ROS 2 `joy` / `joy_linux` 节点和消息频率调整。设备编号以本机检测结果为准。

## 检测设备

你可以在没插手柄的时候看一下：

```bash
ls /dev/input/
```

插上手柄再看一遍。

注意看`js0`,`event15`这种有没有多。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/30/1790302995269-87252e7b.webp)

如上图，对于我来讲我是`js1`和`event24`。

可以用下面这条命令确认下设备名称：

```bash
cat /proc/bus/input/devices
```

按顺序找到`event24`：

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/30/1790303185788-11fafa4f.webp)

## ROS Joy节点


安装`joy`和`joy-linux`包，这俩包分别是俩不同的`joy`节点。

```bash
sudo apt install ros-$ROS_DISTRO-joy
sudo apt install ros-$ROS_DISTRO-joy-linux
```

### Joy

`joy_node` 使用 SDL 设备 ID 或设备名选择手柄，不能使用 `device:=/dev/input/js1`。SDL 设备 ID 与 Linux 的 `js1` 编号不一定相同。先列出设备，再启动节点：

```bash
ros2 run joy joy_enumerate_devices

# 将 0 替换为上一步列出的 SDL 设备 ID
ros2 run joy joy_node --ros-args -p device_id:=0
```

可以看到图里的提示，已经连接到xbox手柄了。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/30/1790303712814-0cb909b8.webp)

查看话题数据：

```bash
ros2 topic echo /joy
```

查看话题的频率：

```bash
ros2 topic hz /joy --window 20
```

`--window 20` 使用较小的统计窗口，能更快反映近期频率变化；它只影响 `ros2 topic hz` 的统计，不改变发布频率。

下面是作者一次测试的频率截图。实际频率取决于设备、节点参数和输入事件，请以本机测量为准。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/30/1790304105972-36829fc9.webp)

### Joy_Linux

试试另一个包：

```bash
ros2 run joy_linux joy_linux_node --ros-args \
  -p dev:=/dev/input/js1
```

可以看到图里的提示，已经连接到xbox手柄了。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/30/1790303712814-0cb909b8.webp)

查看话题数据：

```bash
ros2 topic echo /joy
```

查看话题的频率：

```bash
ros2 topic hz /joy --window 20
```

下面是作者另一次测试的频率截图。静止时是否重发由 `autorepeat_rate` 决定，活动时还受到输入事件与合并间隔影响；不同环境的结果可能不同。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/30/1790305312940-da3c783b.webp)


```bash
ros2 run joy_linux joy_linux_node --ros-args \
  -p dev:=/dev/input/js1 \
  -p autorepeat_rate:=50.0 \
  -p coalesce_interval:=0.01
```

上述参数让静止时按 50 Hz 重发，并在 0.01 秒内合并轴事件。按钮事件仍会立即发布，因此不能把它理解为严格的 100 Hz 上限。请结合控制需求和实测频率调整。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/30/1790305794808-5583031d.webp)

参数说明见 [joy 官方文档](https://github.com/ros-drivers/joystick_drivers/blob/ros2/joy/README.md) 和 [joy_linux 官方文档](https://github.com/ros-drivers/joystick_drivers/blob/ros2/joy_linux/README.md)。
