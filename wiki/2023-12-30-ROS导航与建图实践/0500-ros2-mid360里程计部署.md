本文将简单讲解如何在ros2中配置fastlio2里程计

部署设备：legion y9000p kubuntu22\.04 humble

## 编译Livox\_SDK2

参考：

[mid360\-localization大致流程](/wiki/2023-12-30-ros-dao-hang-yu-jian-tu-shi-jian/0400-mid360-localization-da-zhi-liu-cheng)

## 安装livox\_ros\_driver2包

新建工作空间目录并下载源码,编译

```Bash
mkdir livox_ws&&cd livox_ws
mkdir src
cd src
git clone https://github.com/Livox-SDK/livox_ros_driver2.git ws_livox/src/livox_ros_driver2
cd livox_ros_driver2
./build.sh humble  #如果是Foxy就是./build.sh ros2 不支持jazzy(未经测试，github官网未声明)
```

测试：

```Bash
cd ..
. install/setup.bash
ros2 launch livox_ros_driver2 rviz_MID360_launch.py
```

注意事项：ros2 中所有launch文件和config文件不支持由源码更改应用至ros2 launch脚本，编译时徐需要加上\-\-symlink\-install,livox\_ros\_driver2中的点云格式和ros1中的一致，要想被fast\_lio订阅，格式要调为1\.

## 安装fastlio2功能包

[https://github.com/Ericsii/FAST_LIO_ROS2]()

下载源码，编译

```Bash
cd src
git clone https://github.com/Ericsii/FAST_LIO_ROS2.git
cd ..
colcon build --packages-select fast_lio
```

测试

```Bash
ros2 launch livox_ros_driver2 msg_MID360_launch.py
ros2 launch fast_lio mapping.launch.py
```
