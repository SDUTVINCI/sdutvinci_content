### 环境说明

本教程同时适用于 Windows 和 Linux。Windows 使用 PowerShell，Linux 使用 Bash；文件编辑统一使用 VS Code。

### 安装Git

#### Linux

以下命令适用于 Ubuntu、Debian 及其衍生发行版，其他发行版请使用对应的包管理器安装 Git。

```bash
sudo apt-get update
sudo apt-get install git
git --version
```

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/image2.webp)

#### Windows

详看[MSYS2配置环境教程](/wiki/2023-10-05-cplusplus-jiao-xue/0100-0200-windows-kai-fa-huan-jing-da-jian-yu-ce-shi#%E5%AE%89%E8%A3%85-msys2)，完成 Git 安装和 PATH 配置后，重新打开 PowerShell，确认可以执行：

```powershell
git --version
```

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1793172049293-e03f9d01.webp)

### VScode安装

#### Linux

https://code.visualstudio.com/Download

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2025/07/18/image23.webp)

如果是debian系下载deb,如果是rhel系下载rpm.

下载完之后，点击浏览器，找到这个安装包的文件夹，并在该路径打开终端。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2025/07/18/image24.webp)

Debian系：输入`sudo apt install ./code`然后按`tab`按键补齐文件名，回车。

RHEL系：输入`sudo dnf install ./code`然后按`tab`按键补齐文件名，回车。

例如补齐后的：

```bash
sudo dnf install ./code-1.102.1-1752598767.el8.x86_64.rpm
```

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2025/07/18/image25.webp)

#### 验证

安装完成后，重新打开终端并执行：

```text
git --version
code --version
```

两条命令都能输出版本信息后，即可进入后面的实操。

如果提示找不到 `code`，请检查 VS Code 的安装和 PATH 配置，再重新打开终端。
也可以先从桌面打开 VS Code，通过“文件 → 打开文件夹”进入练习目录，并在编辑器中创建和编辑文件。

### 设置git的用户与邮箱(必须设置！！！)

下面的姓名和邮箱为示例，请替换成你自己的提交署名和邮箱。

```bash
git config --global user.name "tungchiahui"
git config --global user.email tungchiahui@gmail.com
```


### Windows下配置VS Code的Git路径

如果 VS Code 已经能自动识别 Git，可以跳过本节。Linux 用户通常无需配置下面的 Windows 路径。

如果无法识别，按 `Ctrl+Shift+P` 打开命令面板，搜索并选择 `Preferences: Open User Settings (JSON)`：

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1793176249160-f7307fb5.webp)

在设置 JSON 对象中加入以下属性；如果前面已有其他属性，注意用逗号分隔：

```json
{
  "git.path": "C:/msys64/ucrt64/bin/git.exe"
}
```

这里的路径对应 MSYS2 安装在 `C:/msys64`、使用 UCRT64 Git 的情况，请按实际的 `git.exe` 位置填写。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1793176175789-46f94599.webp)

保存后重启 VS Code。
`git.path` 只决定 VS Code 使用哪个 Git，不会修改 PowerShell 的 PATH；终端中的 `git --version` 仍需能够正常执行。
