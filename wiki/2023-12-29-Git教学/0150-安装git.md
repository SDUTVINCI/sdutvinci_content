## Linux

下面以 Debian / Ubuntu 为例安装 Git：

```bash
sudo apt-get update
sudo apt-get install git
git --version
```

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/image2.webp)

## Windows

### 安装 Git

按照[MSYS2配置环境教程](/wiki/2023-10-05-cplusplus-jiao-xue/0100-0200-windows-kai-fa-huan-jing-da-jian-yu-ce-shi#安装-msys2)完成安装和 PATH 配置后，在 PowerShell 中验证：

```powershell
git --version
```

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1793172049293-e03f9d01.webp)

### 配置 VSCode

如果 VSCode 没有自动找到 Git，按 `Ctrl+Shift+P`，打开 `Preferences: Open User Settings (JSON)`：

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1793176249160-f7307fb5.webp)

在设置对象中加入 `git.path`。如果已有其他设置，保留它们并正确添加逗号；默认安装路径的示例如下：

```json
{
  "git.path": "C:/msys64/ucrt64/bin/git.exe"
}
```

如果 MSYS2 安装在其他目录，请修改为实际的 Git 路径。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1793176175789-46f94599.webp)

重启VScode。
