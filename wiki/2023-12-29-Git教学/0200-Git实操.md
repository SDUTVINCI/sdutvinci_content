#### 分支基本操作

1. 分支的作用:开辟项目的一个新仓库分支，与master等其他分支是独立的，可以进行独立的add、commit和diff、clone。

2.  创建分支

```bash
git branch route2
#git branch 分支名
```

3.  进入分支

```bash
git checkout route2
#git checkout 分支名
```

4.  查询有多少分支，并查询目前为哪一个分支

```bash
git branch
```

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/image20.webp)

#### 使用Pull Request合并代码

Pull Request简称PR，用于请求将一个分支中的修改合并到另一个分支。PR可以让项目成员在合并前查看代码变化、留言讨论和进行审查，因此团队协作时通常不会直接将未审查的代码push到main分支。

1.  从main分支创建并进入一个功能分支

```bash
git checkout main
git pull origin main
git checkout -b feature/pr-demo
```

`feature/pr-demo`是本次示例的分支名，实际开发时应使用能表达修改内容的名称。

2.  修改文件并提交到本地仓库

```text
code test1.md
```

在 VS Code 中输入一段正文。

例如

```text
测试1
提交新内容啦！
你好！！！
TEST11111
```

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1793198260946-5336ac4e.webp)

按 `Ctrl+S` 保存，然后回到终端继续操作。

```bash
git add test1.md
git commit -m "修改test1文件"
```

3.  将功能分支推送到Github

```bash
git push -u origin feature/pr-demo
```

`-u`会建立本地分支与远程分支的跟踪关系，之后在该分支上可以直接使用`git push`。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787064461783-99e8dd17.webp)

4.  在Github仓库页面创建PR

推送新分支后，Github仓库页面通常会显示`Compare & pull request`按钮，点击该按钮。如果没有显示，也可以进入仓库的`Pull requests`页面，点击`New pull request`。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787064906162-71445eaa.webp)

确认两个分支选择正确：

- `base: main`：修改最终要合并到的目标分支。
- `compare: feature/pr-demo`：包含本次修改的来源分支。

PR只能在两个不同的分支之间创建。确认下方显示的提交和文件变化没有问题后，填写PR标题和说明，再点击`Create pull request`。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787064943146-74bb95c8.webp)

5.  审查并继续修改PR

创建PR后，可以在`Files changed`页面查看本次修改，也可以邀请其他项目成员进行Review。

#### 向没有写入权限的仓库提交PR

如果想向其他人的开源项目贡献代码，通常没有权限直接将分支push到对方的仓库。此时需要先在Github上点击`Fork`，将该仓库复制到自己的账号下。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1793198628937-2edf1b11.webp)

Fork完成后，克隆自己的仓库并记录原仓库地址：

```bash
git clone https://github.com/你的Github用户名/仓库名.git
cd 仓库名
git remote add upstream https://github.com/原仓库用户名/仓库名.git
git remote -v
```

其中`origin`指向自己Fork出来的仓库，`upstream`指向原仓库。

接下来仍然需要创建功能分支，不要直接在main分支上修改。

```bash
git checkout -b feature/pr-demo
# 修改文件后提交
git add .
git commit -m "添加示例功能"
git push -u origin feature/pr-demo
```

推送后在Github上创建PR，并特别确认：

- `base repository`是对方的原仓库，`base`是对方要接收修改的分支。
- `head repository`是自己Fork的仓库，`compare`是自己刚刚推送的功能分支。

之后填写标题和修改说明，点击`Create pull request`即可向原项目提交PR。

#### 使用VScode图形化提交Pull Request

本节演示如何使用VScode创建、审查和合并Pull Request，整个过程不需要在终端输入Git指令。

> 注意：如果要使用Pull Request，功能分支提交完成后不要执行上文的“切换回main分支”和“合并分支”操作。应当将功能分支保持独立，通过PR审查后再合并到main分支。

1.  安装Github Pull Requests扩展

打开VScode左侧的扩展页面，搜索`GitHub Pull Requests`，安装由Github发布的`GitHub Pull Requests`扩展。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787066639021-9a02afab.webp)

2.  从main创建功能分支

先点击VScode左下角的当前分支名，切换到main分支。

在源代码管理页面点击选择`Pull`，保证本地main分支与Github上的内容一致。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067349047-4d94b8b8.webp)

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067390159-f719aeea.webp)

再次点击左下角的分支名，选择`Create new branch from...`，选择main作为起点，然后输入一个能表达修改内容的分支名，例如`feature/pr-demo`。创建后VScode会自动切换到该分支。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067349047-4d94b8b8.webp)

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067431992-eade67a5.webp)

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067511583-3a757fd7.webp)

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067526052-f9bbf20b.webp)

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067546196-fb5d9180.webp)

1.  修改文件并提交

在功能分支中修改文件并保存，然后打开源代码管理页面：

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067588271-e1b9561b.webp)

- 点击文件右侧的`+`，将修改加入暂存区。
- 在上方输入提交信息，例如`Add PR demo`。
- 点击`Commit`完成本地提交。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067621148-3174d0c2.webp)

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067634417-f8d1f64e.webp)

commit后变为

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067649357-58274e7e.webp)

1.  在VScode中创建PR

打开左侧的Github Pull Requests页面，点击`Create Pull Request`。也可以按`Ctrl+Shift+P`打开命令面板，执行`GitHub Pull Requests: Create Pull Request`。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067711915-86c8f341.webp)

2.  填写PR信息

在Create Pull Request页面中检查以下内容：

- `Base Repository`：接收修改的Github仓库。
- `Base Branch`：要合并进入的目标分支，通常为main。
- 来源分支：当前的功能分支，例如`feature/pr-demo`。
- `Title`：简洁描述本次修改。
- `Description`：说明修改原因、主要内容和验证方法。

也可以根据需要添加Reviewers、Assignees和Labels。检查无误后点击`Create`提交PR；如果修改还没有完成，可以选择`Create Draft`创建草稿PR。


![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067744001-1402f27c.webp)

如果当前分支还没有推送到Github，VScode会提示发布分支。选择`publish branch`即可将当前功能分支推送到远程仓库。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067764516-85017976.webp)


1.  审查并修改PR

创建成功后，VScode会进入PR的Review Mode。在这里可以查看提交记录和文件差异、留言、邀请审查，也可以继续修改代码。

可以查看合并差异:

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067924816-f471716b.webp)

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067950428-546ebd4d.webp)

如果需要根据审查意见修改代码，保持在当前功能分支上，然后继续使用源代码管理页面进行Commit.也就是可以继续修改.

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787067992272-a06147b4.webp)

同样先add再commit本次修改,可以命名为`Add PR demo2`.

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787068021566-fb6e4d49.webp)

最后Push。新的提交会自动加入当前PR，不需要重新创建PR。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787068141475-fe774f6d.webp)

可以看到如图,两次commit都被PR包含了.

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787068203009-6768f4a0.webp)

也可以看到文件差异里,两次提交都被可以被合并到main了.

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787068234996-9c2f6fa0.webp)

1.  合并PR并清理分支

审查通过且自动检查完成后，拥有仓库写入权限的成员可以在PR详情页点击`Merge`完成合并。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787068282082-21f37f97.webp)

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787068295774-46294b05.webp)

合并完成后，VScode会提示删除远程和本地的功能分支。确认PR已经正确合并后再进行删除，最后切换回main分支并点击`Pull`获取最新代码。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787068313339-dfe5dbc9.webp)

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787068345756-fd3adb23.webp)

紧接着PR会被自动关闭.

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1787068378293-1ef31793.webp)
