## Vinci机器人队实验室规章制度

| 行为 | 处理方式 |
| --- | --- |
| 在实验室打游戏看小说刷视频等 | 踢出队伍 |
| 偷盗实验室物资贩卖者，以及其他违法行为 | 交由警察处理并踢出队伍 |
| 经常划水，闲聊等影响队员积极性以及进度 | 踢出队伍 |
| 在大红炉310或106吃饭不打扫和在大红炉310或106吃味大的饭（汤面、米类等） | 打扫实验室一周 |
| 经常迟到不请假者（三次及以上） | 踢出队伍 |
| 无故早退者（二次及以上） | 踢出队伍 |
| 使用工具不放回原处 | 打扫整个实验室 |
| 多次没有完成指定进度的 | 踢出队伍 |
| 不服从实验室管理安排 | 踢出队伍 |
| 私自带外人进入106或者三楼实验室 | 警告加分螺丝 |
| 在实验室内部谈恋爱 | 两个人都踢出队伍 |
| 私自使用3D打印机 | 第一次警告，第二次踢出队伍，如有损坏原价赔偿 |
| 禁止使用大红炉的网络下载Steam等外网的大型游戏 | 警告加收拾大红炉卫生 |
| 顶撞、辱骂学长学姐（对学长学姐不礼貌） | 提出队伍（警告、情节严重者提出队伍） |
| 未经允许拿走实验室机械、电控零件等 | 警告、情节严重者踢出队伍 |
| 不得在106长期存放个人物品，书本、衣物等占用工位 | 警告，收拾走个人物品 |
| 不得在106和310东打地铺睡午觉、过夜 | 警告 |
| 离开实验室无人后关闭所有电源 | 接受大红炉批评，情节严重写检讨 |
| 离开106无人后需锁好密码锁 | 警告 |
