## 社团账号管理

> 安全说明：本文不保存真实账号、手机号、邮箱地址、密码、恢复码、API Token 或其他凭据。相关信息应存放在团队指定的密码管理器中，并仅向获授权成员开放。

### 涉及平台

- 山东理工大学活动申报平台
- 微信及微信公众号
- QQ及QQ邮箱
- 抖音
- 哔哩哔哩
- GitHub
- Docker Hub
- Google
- Cloudflare

### 获取方式

- 账号与凭据由现任负责人通过团队指定的安全渠道提供。
- 不得在Wiki、Git仓库、聊天群文件或公开网盘中保存明文密码。
- 新成员只获取完成职责所必需的平台权限。

### 交接要求

- 负责人变更时应检查账号绑定信息、恢复方式和双重验证设备。
- 完成交接后应及时轮换密码、恢复码和长期访问令牌。
- 成员离队或权限不再需要时，应立即撤销其访问权限。
- 发现凭据泄露时，应立即轮换凭据并检查登录与操作记录。
